LIVE · OPENF1needs backend

This page cannot reach the OpenF1 API directly: the artifact sandbox blocks outbound requests, and OpenF1's real-time feed requires an OAuth token that must never sit in client code. The live path has to terminate in a server you control.

POST https://api.openf1.org/token      → 1h bearer token
wss://mqtt.openf1.org:8084/mqtt       → token as password
  subscribe  v1/location   (x, y, z per driver)
  subscribe  v1/position   v1/intervals   v1/laps
  subscribe  v1/race_control   v1/weather
→ fan out over Socket.IO to every browser

Your backend already has the right shape for this. Replace the 500 ms REST poller in PollingService with one MQTT subscriber and the interpolation guesswork disappears with it.
